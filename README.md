ADO.NET Console Application
Project Description

This is a simple console application built as a training project to practice working with ADO.NET and applying Clean Architecture concepts.

The project focuses on separating responsibilities between layers and keeping the code organized and easy to maintain.

Technologies Used

C#

.NET Console Application

ADO.NET

SQL Server

Project Structure

The project follows a clean layered structure:

Presentation layer for user interaction

Business logic layer

Data access layer using ADO.NET

Features

Display all departments

Add a new department

Delete a department

Purpose

This project was created for learning and practice purposes to better understand:

ADO.NET basics

Clean Architecture

Applying SOLID principles in a simple project
